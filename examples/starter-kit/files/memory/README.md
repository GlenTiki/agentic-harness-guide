# Memory

This folder holds durable facts about the project: decisions, constraints, people's roles and preferences that stay true across sessions. Today's tasks and chat context do not belong here.

## Note rules

1. Write one fact per note. One note is one file, named after the fact in lower case with hyphens, for example `release-needs-two-reviews.md`.
2. Start each note with one description line that says what the fact is and when it applies.
3. Before you write a note, search this folder. Edit the existing note if the fact is already here. Do not write a second note for the same fact.
4. Add one line per note to `INDEX.md`: the file name and its description line.
5. Keep private facts out of the repository. Personal details, credentials, health, salary and client-confidential detail go in a store outside the repository that only the user can read.
6. When a fact stops being true, edit or delete its note and its line in `INDEX.md`.
