# Eval 1: a vague budget ask

## Input

```text
Help me make a budget.
```

## A good refinement must

- Not produce a budget, a template with figures, or budgeting advice.
- Ask no more than three questions, each with a recommended default (for example: household or business, monthly, in the user's own currency).
- List its assumptions.
- Use all seven sections.
- Mark the user's income, spending and currency as [NEEDED], not as numbers.
- Say that figures must come from the user's own statements.
- Include a definition of done the user could check, for example that the totals add up and match a real statement.

## It fails if

- It invents income, rent or any other figure.
- It answers with a budget.
- It asks four or more questions, or a question with no default.
- It leaves out a section.
