## Questions

1. **Scope:** Should this cover visual styling only, or also layout, copy and form UX? *Recommended default: visual styling and layout only. No changes to form fields, validation or behavior.*
2. **Brand:** Is there a brand guide, design system or existing palette to follow? *Recommended default: reuse whatever colors, fonts and components the site already uses.*
3. **Responsiveness:** Does it need to work on mobile and desktop? *Recommended default: yes, both.*

## Assumptions

- "Our signup page" is an existing page in a codebase the assistant can access.
- "Professional" means clean, consistent, trustworthy-looking, not a full redesign.
- Functionality, routes and backend stay unchanged.
- The user wants the changes made directly, not just suggested.
- Accessibility basics (contrast, labels, focus states) count as part of looking professional.
