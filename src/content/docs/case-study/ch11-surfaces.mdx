*Audience: a reader who wants to build along. An agent must not run any command on this page unless the user asks for it in the current session.*

**Status.** Built in the case study. Every command and output below was run on 2026-10-25 from a fresh unzip of `ch11-surfaces.zip`, with Python 3.13.1.

**Time.** Running the steps takes about 10 minutes (8 steps, [counted like this](../#how-to-use-a-chapter)). Reading the code takes longer: about 20 to 30 minutes more.

## The weak spot

Tools cannot see each other. Each starts blank and keeps its own rules, which drift apart.

## Goal

Keep one source of rules for several tools, and pass messages between [agents](../../glossary/#agent) as files anyone can read.

## What is in the kit

- `example/project/` with a shared `AGENTS.md`, a `CLAUDE.md` that holds `@AGENTS.md` plus a few tool-specific lines, and a `.gemini/settings.json` that names `AGENTS.md`.
- `layout.py`, which checks that the files exist, that `CLAUDE.md` imports `AGENTS.md` and does not copy its lines, and that the Gemini setting includes `AGENTS.md`.
- `exchange.py`, a plain-text message exchange. A message is a Markdown file with a header (`from`, `to`, `time`, `subject`, `status`, `re`) in a folder named `to-<name>/`. Commands: `post`, `inbox` and `check`.
- `validate.py` and failing fixtures for both the layout and the exchange.

## Get the kit

Download [ch11-surfaces.zip](/agentic-harness-guide/downloads/ch11-surfaces.zip). Then run these commands in the folder that holds it:

```text
shasum -a 256 ch11-surfaces.zip
unzip ch11-surfaces.zip -d kit
cd kit/ch11-surfaces
```

The hash must be `321c244b9169bf4ea3e5f27698b66b162bdd53ad088677dbceffddba118072eb`. If it differs, stop. On Linux use `sha256sum`. This folder is the kit root. Run every command from it. [How the kits work](../#how-to-use-a-chapter).

## Steps

1. Compare the checksum, then unzip (see above).
2. Read `example/project/AGENTS.md`, `CLAUDE.md` and `.gemini/settings.json`.
3. Check the layout: `python3 -I layout.py example/project`.
4. Read the two messages in `example/exchange/`. The reply names the first message in its `re` line.
5. List an inbox: `python3 -I exchange.py --root example/exchange inbox claude`.
6. Post a message into a scratch folder, then check that folder.
7. Run the validator: `python3 -I validate.py`. It prints `validate: PASS`.
8. Prove the check can fail: `python3 -I validate.py --bad`. The exit code is 1.

## What is not tested

Verified by tests: the layout check, the message format, the safe write and 8 concurrent posts. Not verified: how any real tool behaves when it reads these files. The statements about Claude Code, Codex and Gemini come from their documentation, which the setup page quotes with its fetch date. Nobody ran this layout in those tools for this chapter. A polling convention is not a real-time channel. An agent only sees a message when it looks. [MCP](../../glossary/#connector-mcp), ACP and A2A are described in the spec and not built.
