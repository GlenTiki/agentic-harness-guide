Each workflow takes one real job and walks it through a refinement loop. The linked levels explain the ideas each workflow uses. The tag says what you need.

For a household chore without code, start with [one small tool brief](../method/be-the-product-manager-of-your-own-tooling/#start-with-one-small-tool). You can decide whether to build anything after you have tried the smallest version.

<WorkflowGrid />

1. [Workflow: build a budget](./build-a-budget/): Build a budget for a small shop with the assistant, and check the totals. Pairs with [level 1](../journey/01-say-it-properly/) and [level 5](../journey/05-check-the-work/). *Chat only (a spreadsheet helps).* Try it: about 7 steps.
2. [Spreadsheet Monday](./spreadsheet-monday/): Use the assistant to write formulas you can check, instead of adding in prose. Pairs with [level 5](../journey/05-check-the-work/). *Chat and a spreadsheet; needs bookkeeping knowledge.* Try it: 25 minutes.
3. [Review content](./review-content/): Review writing against a brief, with source evidence when checking facts. Pairs with [level 5](../journey/05-check-the-work/). *Chat only.* Try it: 20 minutes.
4. [Improve code](./improve-code/): Refine a piece of code in small, tested passes with an independent review. Pairs with [level 5](../journey/05-check-the-work/). *Needs code.* Try it: about 14 steps.
5. [Improve a design](./improve-design/): Refine a layout or visual design against a written brief and a checklist. Pairs with [level 5](../journey/05-check-the-work/). *Chat only to start; needs five real people for the last step.* Try it: about 11 steps, then a test with five people.
6. [Connect systems](./connect-systems/): Decide what to connect, in what order, with what access. Pairs with [level 3](../journey/03-give-it-hands/) and [level 4](../journey/04-trust-but-verify/). *Needs connected tools.* Try it: 15 minutes.
7. [Small shop month-end](./small-shop-month-end/): Work through a credible September month-end, from proving sales to the bank to sign-off. Pairs with [level 5](../journey/05-check-the-work/). *Chat and a spreadsheet; needs bookkeeping knowledge.* Try it: 30 minutes.
8. [Define a workflow](./define-a-workflow/): Turn a repeated job, such as onboarding a new hire, into a written workflow with steps, checks and stop points. Pairs with [level 8](../journey/08-design-anything/). *Chat only.* Try it: 10 minutes.
9. [Research a decision](./research-a-decision/): Research a choice with sources, a comparison table and a stated recommendation. Pairs with [level 8](../journey/08-design-anything/). *Chat only.* Try it: 10 minutes.
10. [Design reps](./design-reps/): Practise the six-step method on five more jobs, such as triaging a shared inbox. Pairs with [level 8](../journey/08-design-anything/). *Chat only, plus pen and paper.* Try it: about 3 steps a rep.
11. [Build a kitchen assistant](./build-a-kitchen-assistant/): Build four small, tested scripts that catalogue recipes, track stock, make a shopping list and suggest a dish. Pairs with [level 8](../journey/08-design-anything/). *Needs Python 3 and a terminal.* Try it: about 10 steps.
