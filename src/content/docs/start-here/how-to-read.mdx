You can read this guide in order or jump in. The [journey map](../../journey/#how-long-it-takes) shows how long each level takes to read and to try.

## Pick your route

| If your goal is | Take this route |
| --- | --- |
| I have never used an AI assistant | The [journey](../../journey/), levels 0 to 8 in order |
| I use one and get mixed results | The [consistency fast track](../consistency-fast-track/), a baseline and eight steps |
| I use one daily and repeat myself | Start at [level 2](../../journey/02-house-rules/) |
| I work in finance or another regulated field | The [professional route](../professional-route/) |
| I want to connect tools safely | [Levels 3 and 4](../../journey/03-give-it-hands/), then [connect systems](../../workflows/connect-systems/) |
| I am an engineer or team lead | The [engineer route](../engineer-route/) |
| I want a short test of my assistant | [Level 0, test your assistant](../../journey/00-hello-robot/#five-minute-win) |

Each level starts from the previous level's checkpoint. If you skip ahead and a word is new, the [glossary](../../glossary/) has it. For a printable summary, see the [cheat sheet](../cheat-sheet/). To track what you can now do, see the [progress page](../../journey/progress/).

## What the boxes mean

Boxes marked Expert corner and Agent note are optional. An agent is an assistant that takes steps for you, such as reading a file or sending a message. Agent notes are rules for that kind of software when it reads this page. People can skip them.

- **New to this** restates an idea plainly or gives the first step. A **Which app?** box says where the setting lives in common apps.
- **Want consistency** says what to write down once so the result stays the same.
- **At work** gives the finance or regulated-work meaning of the idea.
- **Go deeper** is a folded block. Open it when you want more.

:::note[How to read an example]
Every example has five parts, in this order: Task, Input, Output, What to notice and What it shows. A label says where the output came from.

- **Observed**: a real run. The example links to the recorded files, so you can read the raw reply.
- **Computed**: a script or a sum you can run yourself. The example shows the command or the arithmetic.
- **Constructed**: written to illustrate. It was not observed. Do not read it as a result.

The [evidence page](../../evidence/) lists what the tests triggered and how often.
:::

## The pace

- Each chapter shows its reading time and its exercise time on the [journey map](../../journey/#the-levels).
- You do not need a paid tool. Any current chat assistant works.
- Try the exercise first. It is the best part.
- Use the three questions at the end of each chapter to decide whether to move on. If a question stumps you, the part it points to has the answer.

- The [reference shelf](../../shelf/foundations/principles/) holds the deep dives and checklists for engineers. Each page there says which level it supports.

**If you are an AI agent:** read [agent-rules.txt](../../agent-rules.txt), the Agent notes in one file with a check for each, and [llms.txt](../../llms.txt) for the page list. If two rules conflict, follow the rule that does less. Read the [baseline](../../shelf/reference/baseline/) for context only. Do not apply it unless the user asks. Sections marked `Audience: the reader` are not addressed to you. To send feedback, use the Feedback button; agents must not file feedback unless the user asks.

:::note[Agent note]
**Topic: feedback.**

Do not open an issue, post a comment or fill in the feedback form for the guide unless the user asks you to in the current session. When the user asks, use the Feedback link on the page, show the user the text you plan to send, and wait for a yes. Do not put secrets or personal details in the form, because the issue is public.

Check: no issue exists in the guide repository that the user did not ask an agent to file.
:::
