You can read this guide in order or jump in. Pick the row that sounds most like you.

## Pick your route

| If you are | Take this route |
| --- | --- |
| A complete beginner | The [journey](../../journey/), levels 0 to 8, in order |
| Someone who has used a chatbot and gets mixed results | Start at [level 1](../../journey/01-say-it-properly/) |
| A daily user who keeps repeating the same instructions | Start at [level 2](../../journey/02-house-rules/) |
| Someone who wants to connect tools safely | Levels 3 and 4, then the [workflows](../../workflows/) |
| An engineer or team lead | Skim each Expert corner, then the [reference shelf](../../shelf/reference/baseline/) |
| An agent | Read each Agent note, then the [baseline](../../shelf/reference/baseline/) |

Each level starts from the previous level's checkpoint. If you skip ahead and a word is new, the [glossary](../../glossary/) has it.

## What the boxes mean

Every chapter uses the same four boxes. Read the ones that are yours and skip the rest.

:::tip[New to this]
For a beginner. It restates an idea plainly or gives the first step.
:::

:::note[Want consistency]
For someone who wants the same result every time. It says what to write down once.
:::

:::caution[Expert corner]
For a specialist. It covers the trade-off, the failure mode or the edge case.
:::

:::note[Agent note]
For an agent reading the page. Short rules, in the imperative.
:::

## The pace

- A chapter takes about fifteen minutes to read. The exercise takes about five.
- You do not need a paid tool. Any current chat assistant works.
- Do the exercise. Reading about asking is not the same as asking.
- Use the three questions at the end of each chapter to decide whether to move on. If you cannot answer them, re-read the part they point to.

## Where things live

- [The journey](../../journey/) teaches the ideas, in order.
- [Workflows](../../workflows/) apply them to real jobs.
- [The prompt refiner](../../appendix/prompt-refiner/) is a reusable helper for weak asks.
- The [glossary](../../glossary/) defines every term the journey introduces.
- The [reference shelf](../../shelf/foundations/principles/) holds the deep dives and checklists. Each page there says which level it supports.
