---
title: The consistency fast track
description: A 90 minute route of eight timed steps for people who want repeatable results from a chat assistant.
---

This route is for you if you already use an assistant and the results vary. Consistent means the same structure, figures and quality, not the same words. Use your own task throughout. Where a step needs numbers, the shared-bills example supplies them.

## The eight steps

Times are about, and include reading.

1. **15 minutes: see the problem.** Do [level 0, Try it](../../journey/00-hello-robot/#try-it). Notice that the same question gives different answers, and that a total can be wrong while sounding sure.
2. **15 minutes: write the ask properly.** Do passes 1 to 3 in [level 1, Try it](../../journey/01-say-it-properly/#try-it): goal, constraints and an example. Use a task of your own.
3. **5 minutes: add a check step.** Do the check pass in [level 1, Try it](../../journey/01-say-it-properly/#try-it). Ask the assistant to count and to list anything it assumed.
4. **5 minutes: save the ask as a template.** Copy the final ask into a note with the blanks marked: the task, the material, the limits. Next time, fill the blanks. Do not start from memory.
5. **15 minutes: save your standing rules.** Do [level 2, Try it](../../journey/02-house-rules/#try-it). Write the short instruction file once, so you stop repeating it.
6. **20 minutes: test the ask on three cases.** Do the three-case table in [level 5](../../journey/05-check-the-work/#a-tiny-eval-table). Run your template on a normal case, an awkward case and a case with a trap. Mark each one pass or fail.
7. **10 minutes: tidy the chat.** Read the context habits in [level 2](../../journey/02-house-rules/#the-idea). One job per chat. Restate the key facts. Start a fresh chat when a long one drifts.
8. **5 minutes, optional: try the short refiner.** Paste [the short refiner prompt](../../appendix/prompt-refiner/#refiner-lite) with your weakest ask and see what it adds.

## What to skip

Skip levels 3, 4, 6, 7 and 8 and the reference shelf for now. Come back to [level 4](../../journey/04-trust-but-verify/) only if you connect email or files. Those levels are about tools and systems of several assistants, not about repeatable chat results.

## The three habits

1. **Ask with a goal, limits, an example and a check.** The same shape every time gives the same quality.
2. **Write the rules down once.** A saved template and a short instruction file beat memory.
3. **Make it show its counting.** Ask for the count and the sum before the total. A list of 13 figures that should be 12 shows up at once.
