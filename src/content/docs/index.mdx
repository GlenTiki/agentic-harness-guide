An agentic harness is the set of limits and checks around an assistant that takes steps for you. It makes the work dependable and checkable. When the same slip comes back, use the [weak-spot loop](./method/engineer-weak-spots/#the-loop): notice it, name it, engineer a fix, prove the fix can fail, keep it.

## Start here

1. **Test your assistant.** [Level 0](./journey/00-hello-robot/#five-minute-win) shows how to catch a wrong total with a spreadsheet check.
2. **Pick your route.** [Choose a route](./start-here/how-to-read/) by how you use an assistant: at work, in a chat window, or as an engineer.
3. **Keep one prompt.** [Refiner lite](./appendix/prompt-refiner/#refiner-lite) tightens a vague ask. Paste it into any chat assistant.
