Language models predict tokens; they do not manage state. Left unguided in a chat window, multi-step work collapses into confident hallucinations, dropped constraints, and silent corruption.

An agentic harness is the deterministic engineering layer around the model: isolated workspaces, capability gates, interceptor hooks, and mechanical checks that turn probabilistic chat tools into dependable production engines. When the same slip comes back, use the [weak-spot loop](./method/engineer-weak-spots/#the-loop): notice it, name it, engineer a fix, prove the fix can fail, keep it.
